CHROME EXTENSION

A clearer view of your task time.

MangoMinder provides automatic task timing, submit-click counting, reminders, and saved dark mode on supported Multimango and Parimango pages.

Chrome Web Store release in preparation

The store installation link will be added here once MangoMinder is published.

Automatic timing

Elapsed time updates every second using supported task-acquisition and heartbeat responses, including when no time limit is supplied.

Time at a glance

See elapsed whole minutes on the toolbar badge or use the optional draggable page timer. The popup shows a separate time limit when available.

Submit-click counter

Count clicks on matching button labels. Customize those labels and reset the counter from the popup.

Reminders and appearance

Choose an optional chime with a delay of at least 30 seconds, and save a dark-mode preference for each supported site.

Using MangoMinder

An existing platform account is required for the task workflow. MangoMinder does not provide account access. Task detection depends on supported API responses and may need updates when the platform changes.

The counter records matching button clicks rather than server-confirmed completed tasks. Browser background scheduling can delay reminders.

Privacy

Task-clock state and counts are stored in browser extension storage. Notification settings and tracked button labels may sync through Chrome. MangoMinder includes no analytics or developer-operated task-data collection endpoint.
