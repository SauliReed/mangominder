What MangoMinder does

MangoMinder provides task timing, submit-click counting, reminders, and a saved page-theme preference on supported Multimango and Parimango sites.

Information processed

The extension observes supported heartbeat and task-acquisition requests and responses already made by the supported site. It parses relevant API payloads in memory to extract task identifiers, item identifiers, heartbeat success, and an optional task time limit. Task-acquisition payloads may contain task content, but MangoMinder does not persist prompts or generated answers. It stores the identifiers needed to distinguish tasks and items.

The extension also reads labels of clicked button-like elements to count matching submit clicks, checks the supported site's origin and relevant routes for timer behavior, and checks whether a page for a tracked origin remains open so pending reminders can be cancelled. It does not maintain a history of destinations visited outside the supported sites.

Browser storage

Local extension storage holds per-origin counts, the latest matching-click timestamp, task and item identifiers, timer start/reset timestamps, time limits, reminder state, timer visibility and position, and page-theme preferences. Session storage holds associations between supported site origins and tab identifiers to help handle tab closure.

Chrome sync storage holds configurable tracked button labels and notification preferences. Chrome may synchronize those settings through your Google account when sync is enabled. Do not enter confidential information as a custom tracked label.

How information is used

Information is used to provide the visible timer, counter, reminders, and appearance settings, and to reset timing or cancel reminders when appropriate. MangoMinder does not sell information, use it for advertising, or use it to assess creditworthiness. Information is used only for the extension's stated features.

Transmission and third parties

MangoMinder has no developer-operated data collection endpoint, analytics service, or advertising integration. It does not initiate additional task or heartbeat requests. The supported website continues to make its own requests under its own policies. Chrome sync, when enabled, handles the synchronization of the settings described above under Google's applicable policies.

Retention and controls

Current timer and item state is overwritten as tasks change or resets occur; MangoMinder does not store an ongoing task history. Counts and preferences remain in browser extension storage until reset, changed, cleared, or removed by Chrome. The popup Reset button clears the counter for the active site, not all extension data. Removing the extension clears its local extension storage through Chrome; management of synchronized data depends on Chrome and Google account settings.

Changes and contact

We will update this policy when the extension's data practices change. Questions may be sent to the contact listed above.
